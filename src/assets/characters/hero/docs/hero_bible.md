# Smart Parrot Hero Bible v1.0

Status: Approved foundation

## Character role

The hero is a young traveler entering an English-speaking world for the first time. The player should immediately read the character as curious, approachable, brave, and slightly nervous—but ready for adventure.

## Recognition system

The hero must remain recognizable through three signature elements:

1. Purple hoodie
2. Purple hard-shell suitcase
3. Pico, the green parrot companion

These elements should survive silhouette tests, small UI portraits, mobile rendering, and marketing crops.

## Appearance

- Young traveler
- Friendly, universal facial design
- Soft stylized realism
- Expressive eyes and readable brows
- Athletic everyday proportions rather than superhero proportions
- Approximately 6.5 heads tall

## Personality

- Curious
- Courageous
- Polite
- Optimistic
- Empathetic
- Slightly nervous in unfamiliar situations
- Learns through exploration and conversation

## Locked outfit

- Purple hoodie
- Navy travel jacket
- Grey undershirt
- Blue jeans
- White trainers
- Brown leather backpack
- Purple hard-shell rolling suitcase

Avoid unnecessary visual noise, excessive logos, tactical styling, or fashion details that date the character too quickly.

## Companion relationship

Pico is a permanent companion, guide, and friend—not a decorative pet. The hero should naturally look toward Pico, react to Pico's cues, and share celebratory and reassuring moments with him.

## Expression set

Required expressions:

- Neutral
- Happy
- Laughing
- Amazed
- Curious
- Thinking
- Nervous
- Confused
- Determined
- Proud
- Celebrating

Expressions must remain readable at dialogue-portrait scale.

## Core animation set

### Locomotion

- Idle
- Walk
- Run
- Sprint
- Turn
- Jump
- Land
- Crouch

### Travel interactions

- Pull suitcase
- Lift suitcase
- Open suitcase
- Put on backpack
- Remove backpack
- Adjust backpack strap

### Social and learning

- Wave
- Point
- Nod
- Shake head
- Clap
- Listen carefully
- Repeat a word
- Read a sign
- Celebrate mastering a phrase
- High-five Pico

## First playable context

The first vertical slice begins at Heathrow Airport. The hero retrieves the purple suitcase, meets Pico, completes a first spoken-English interaction, follows airport signage, and begins the journey toward central London.

## Production rules

- Preserve the approved silhouette and signature colors.
- Use PBR-compatible materials.
- Keep runtime exports browser- and mobile-friendly.
- Maintain consistent real-world scale across the hero, suitcase, Pico, and environment.
- Export runtime assets as GLB unless a documented exception is required.
- Keep source files and runtime exports clearly separated.
