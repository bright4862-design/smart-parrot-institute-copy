# Smart Parrot Hero

Production assets for the main traveler character.

## Folders

- `concepts/` — Approved character sheets, turnarounds, expression sheets, and proportion studies
- `references/` — Clothing, luggage, material, pose, and location references
- `models/` — High-poly source, retopology source, and optimized runtime models
- `textures/` — Character texture sets and packed runtime maps
- `materials/` — Material definitions and implementation notes
- `rig/` — Body rig, facial rig, control-rig notes, and skeleton exports
- `animations/` — Source animation clips and optimized runtime clips
- `audio/` — Footsteps, clothing, luggage, and character foley
- `icons/` — Portraits, inventory art, and UI thumbnails
- `docs/` — Character bible, palette, naming, export, and animation documentation

## Runtime target

The browser-ready hero should ship as an optimized GLB with consistent scale, named animation clips, compressed textures, and a stable skeleton suitable for reusable animation.
