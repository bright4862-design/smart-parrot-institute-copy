# Smart Parrot Character Assets

This directory contains the production assets and documentation for Smart Parrot's game characters.

## Structure

- `hero/` — main playable traveler character
- `pico/` — Pico, the parrot companion
- `shared/` — shared animation, material, rigging, and export standards

## Production principle

Character assets should remain modular, browser-ready, mobile-conscious, and compatible with the runtime contracts documented in each character folder.
