# Pico Companion Assets

Production home for Pico, the permanent Smart Parrot companion.

## Planned folders

- `concepts/`
- `references/`
- `models/`
- `textures/`
- `materials/`
- `rig/`
- `animations/`
- `audio/`
- `icons/`
- `docs/`

## Core behavior set

Pico must support perching, flying ahead, landing, pointing toward objectives, reacting to player mistakes, celebrating successes, and sharing quiet idle moments with the hero.

Pico should feel like a guide and friend, never a floating quest marker with feathers.
