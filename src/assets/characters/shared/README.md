# Shared Character Library

Reusable production assets shared by the hero, Pico, and future NPCs.

## Planned folders

- `skeletons/` — Stable reusable skeleton definitions
- `animations/` — Shared locomotion and interaction clips
- `materials/` — Common character materials
- `shaders/` — Browser-safe character shader helpers
- `icons/` — Shared UI portrait conventions and frames
- `docs/` — Naming, scale, export, and compression standards

Shared assets must remain backwards-compatible whenever possible. Breaking skeleton or animation changes require a documented version bump.
